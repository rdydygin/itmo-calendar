# Запуск на VPS

Основано на https://github.com/iburakov/my-itmo-ru-to-ical (MIT).
Нужны Docker Compose, домен с A-записью на VPS и свободные открытые TCP-порты 80/443.

```bash
cp .env.example .env
cp isu.env.example isu.env
chmod 600 .env isu.env
nano .env
nano isu.env
docker compose up -d --build
docker compose logs calendar
```

В `.env` задайте CALENDAR_DOMAIN, в `isu.env` — логин и пароль ИСУ.
Секреты задавайте локально на VPS. Не коммитьте их и не публикуйте путь календаря.
Caddy автоматически получает HTTPS-сертификат.

В логах найдите `URL path for calendar: /calendar/...`.
Добавьте https://ВАШ-ДОМЕН/calendar/СЕКРЕТНЫЙ-ПУТЬ в веб-версии Google Calendar:
Другие календари → + → По URL. Это подписка, не разовый импорт.
Google сам определяет частоту обновлений. На телефоне включите календарь в том же аккаунте.
Смена учётных данных ИСУ меняет ссылку календаря.

События сериализуются в UTC и отображаются в часовом поясе пользователя.
Источник — API личного расписания. Физра и бронирования попадут в календарь,
только если они присутствуют в ответе этого API; отдельные источники не добавлены.

Исправления: необязательный zoom_url, штатная сериализация ICS с CRLF,
удаление HTML страницы ошибки входа из сообщения исключения.
Используйте сохранённый poetry.lock: установка зависимостей без него может
подтянуть несовместимую версию TatSu.
